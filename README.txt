PROJETO: Meu Pet Shop

Nome do autor: Márcio André da Cunha Silva 

TECNOLOGIAS UTILIZADAS

* HTML
* CSS
* JavaScript

ETAPAS DE DESENVOLVIMENTO

1. Estrutura HTML

* Cabeçalho com navegação;
* Seção de Destaque;
* Seção Sobre;
* Seção de Serviços;
* Seção de Contato e Interatividade;
* Rodapé.

2. Estilização com CSS

* Paleta de cores temática;
* Tipografia personalizada;
* Layout utilizando Flexbox;
* Responsividade para dispositivos móveis;
* Cards de serviços;
* Uso de aspect-ratio;
* Elementos posicionados com position relative e absolute.

3. Interatividade com JavaScript

Validação do formulário de contato:

* Verificação de campos obrigatórios;
* Validação de tamanho mínimo e máximo;
* Validação de formato de e-mail utilizando Regex.

COMO EXECUTAR OS PROJETOS

1. Extraia os arquivos do projeto.
2. Abra a pasta do projeto.
3. Execute o arquivo "index.html" em um navegador de internet.
